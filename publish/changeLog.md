### v2.1.13 隐私保护

- 账号、设备和认证信息不再直接写入连接日志；应用日志对常见凭据、联系方式和本机路径做尽力脱敏。
- 增加敏感文件忽略规则与发布前隐私回归检查；历史提交和旧日志不自动删除。
- Docker Hub Overview 随 README 独立自动同步，并读取公开内容验证结果。
- 保持现有客户端和数据目录兼容，公网部署仍须使用 HTTPS/WSS。
